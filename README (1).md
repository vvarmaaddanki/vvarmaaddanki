**Tech:** `Python` · `LangGraph` · `LLMs` · `GitHub API`

**Problem:**
Manual code reviews are slow, inconsistent, and expensive. Engineering teams lose hours every week reviewing pull requests — often missing subtle bugs, security vulnerabilities, or style violations in the process.

**What I built:**
An autonomous multi-step AI agent powered by LangGraph and LLMs that automatically reviews GitHub pull requests end-to-end — it reads PR diffs, reasons about code quality, detects issues, and posts structured inline review comments directly via the GitHub API, all without human intervention.

**Key Results:**
- 🔄 Built a fully autonomous PR review pipeline using LangGraph's stateful multi-step agent architecture
- 🔍 Integrated LLMs to detect code smells, anti-patterns, potential bugs, and security risks
- 🔗 Connected to the GitHub API to read diffs and post structured inline review comments automatically
- 🏗️ Designed a modular agent that can be extended across multiple repositories and code styles

**Tech:** `JavaScript` · `Node.js` · `WebSockets`

**What I built:**
A real-time chat API using Node.js and WebSockets that enables instant bidirectional messaging — featuring multi-room conversations, live message broadcasting, connection state management, and support for concurrent users.

**Key Results:**
- ⚡ Implemented persistent WebSocket connections enabling real-time bidirectional messaging with near-zero latency
- 🏠 Built multi-room chat functionality with isolated message broadcasting per room
- 👥 Handled multiple concurrent user connections with proper lifecycle management (connect / disconnect / reconnect)
- 📡 Eliminated polling overhead with persistent socket connections for efficient server resource usage
